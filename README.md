Clarifai is an AI computer vision and NLP platform providing REST and gRPC APIs for image recognition, object detection, text analysis, visual search, and custom model training. The platform enables teams to build, deploy, and manage AI across shared cloud, on-premise, and edge infrastructure with support for model inference, workflow orchestration, vector search, and dataset management.

**Areas:** Artificial Intelligence · Computer Vision · Natural Language Processing · Image Recognition · Object Detection · Text Analysis · Visual Search · Machine Learning · Custom Model Training · gRPC

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Clarifai: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
